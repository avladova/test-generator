## Что изменено

### 1. Проверка формул

Для вопросов с `type: "formula"` приложение сначала нормализует ответ:

- удаляет пробелы;
- приводит Unicode-минусы и знаки умножения к стандартной записи;
- понимает степени `^`;
- понимает Unicode-верхние и нижние индексы;
- приводит `Cₙᵏ`, `C(n,k)` и близкие записи к общей форме;
- допускает круглые/квадратные/фигурные скобки в записи.

Например, записи

`C(n,k)=n!/(k!(n-k)!)`

и

`C(n,k) = n! / [k! (n-k)!]`

считаются одной математической записью.

Это не полноценный CAS и не доказывает произвольную алгебраическую эквивалентность. Проверяется именно нормализованная структура формулы.

### 2. Статистика

В браузере сохраняются:

- число сгенерированных тестов;
- число сгенерированных вопросов;
- число проверенных ответов;
- число использованных тем;
- число повторных попыток.

Повторная попытка — повторный запуск теста по уже использованной теме.

Статистика хранится в `localStorage` и поэтому является статистикой конкретного браузера/устройства. Она не объединяется между студентами.

Для общей статистики по всем студентам потребуется отдельный серверный или аналитический компонент; GitHub Pages сам по себе не предоставляет общего хранилища событий.

Кнопка «Сбросить локальную статистику» очищает только статистику текущего браузера.
