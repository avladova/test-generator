Как проходить тест

  1. Выберите тему из оглавления.
  2. Выберите количество вопросов и нажмите «Начать тест».
  3. Отвечайте своими словами. Минимального объёма ответа нет.
  4. Для формулы запишите её и объясните основные обозначения; для метода укажите назначение и основные этапы.
  5. Если вопрос требует формулу, можно использовать обычные символы клавиатуры: ^ для степени, ! для факториала, / для дроби.
  6. Нажмите «Проверить ответ» для диагностической оценки.
  7. «Следующий вопрос» можно нажать в любой момент — вопрос разрешается пропустить.
Важно. Проверка выполняется непосредственно в браузере по структурированному индексу. Это диагностическая, а не экспертная оценка.
