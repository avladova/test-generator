Тестирование по фиксированному учебнику В. И. Соловьева. Студенту PDF загружать не нужно.

Как проходить тест

  1. Выберите тему из оглавления учебника.
  2. Выберите количество вопросов и нажмите «Начать тест».
  3. Отвечайте своими словами. Минимального объёма ответа нет.
  4. Для формулы запишите её и объясните основные обозначения; для метода укажите назначение и основные этапы.
  5. Нажмите «Проверить ответ» для диагностической оценки.
  6. «Следующий вопрос» можно нажать в любой момент — вопрос разрешается пропустить.
Важно. Проверка выполняется непосредственно в браузере по теоретическим материалам выбранного раздела. Это диагностическая, а не экспертная оценка.
