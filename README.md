# Генератор диагностических тестов — «Анализ данных в экономике»

В репозитории хранится заранее подготовленный `data/book_index.json`. Браузер загружает индекс, показывает темы из оглавления и формирует вопросы на основе содержательных фрагментов выбранного раздела.

Проверка ответа выполняется локально в браузере, без платного LLM и без отправки ответа студента на внешний сервер. Оценка использует ключевые слова и содержательный контекст выбранной темы.

## Инструкция студенту

1. Откройте сайт.
2. В поле «Тема» выберите нужный раздел учебника.
3. Выберите количество вопросов.
4. Нажмите «Начать тест».
5. Прочитайте вопрос полностью.
6. Ответьте своими словами. Рекомендуемый объём — не менее 30 слов.
7. Для определения укажите само определение и существенные признаки.
8. Для метода или алгоритма укажите назначение и основные этапы.
9. Для классификации назовите основные группы и поясните различия.
10. Если требуется формула, запишите её и расшифруйте обозначения.
11. Нажмите «Проверить ответ».
12. После проверки нажмите «Следующий вопрос».
13. После последнего вопроса сайт покажет средний диагностический результат.

### Почему не стоит писать ответ коротко

Ответ из одного-двух слов может содержать правильный термин, но не показывает, понимает ли студент содержание темы. Поэтому система учитывает объём ответа: короткие ответы получают понижающий коэффициент.

### Как повысить качество ответа

Не копируйте случайный фрагмент текста. Сформулируйте ответ самостоятельно и включите несколько содержательных элементов: определение понятия, свойства, условия применения, этапы метода, классификацию, взаимосвязи или формулу с расшифровкой обозначений — в зависимости от вопроса.

### Что означает результат

`Зачтено` — ответ достаточно близок к содержательному материалу выбранной темы.

`Частично` — часть ключевых элементов присутствует, но ответ недостаточно полный или близкий к материалу.

`Не зачтено` — существенного соответствия материалу темы не обнаружено либо ответ слишком короткий.

Автоматический результат является диагностическим и не заменяет проверку преподавателем.

## Структура

```text
index.html              # сайт
style.css               # оформление
app.js                  # генерация вопросов и проверка ответов
data/
  book_index.json       # индекс фиксированного учебника
README.md               # инструкция
```


## Обновление учебника

Студенческая версия намеренно не содержит загрузчика PDF. Учебник считается фиксированным. Если преподаватель решит заменить учебник, сначала создаётся новый `book_index.json` в преподавательской/Colab-версии, после проверки структуры и оглавления файл заменяется в `data/` этого репозитория.
